# v47 복합 관계·후일담·분기 탐색·저장 검사

## 공식 설정(유지)
- 다니엘 레온하르트는 알렉스 레온하르트의 동생이며, 미겔 코트리먼과 알렉스는 약혼 관계다.
- 미겔은 자신의 책임과 원칙을 중시하며 알렉을 직접 부를 때 ‘알렉’이라고 한다.
- 이 문서의 사건과 대사, 후일담은 모두 게임용 각색이며 공식 정사에 편입되지 않는다.

## 게임용 각색 v47
- v46의 미겔·알렉·황궁 소문 3단계 결말을 조건으로, 각각의 2지선다 교차 후일담을 개방한다.
- 미겔: 존중하며 물러서기 / 답을 요구하지 않고 감정을 정리하기. 감정·절제와 알렉의 신뢰·의심을 대사에 반영한다.
- 알렉: 화해를 먼저 제안하기 / 의심을 숨기지 않고 대화하기. 형제 신뢰 수치가 대사와 후속 결과에 영향을 준다.
- 황궁 NPC: 소문의 출처 확인 / 추측의 전달 중단. 다섯 장소의 관계망 파급 수치를 별도 기록한다.
- 최초 선택에서 2일 간격으로 네 단계의 후속 장면이 발생한다. 완료 시 선택의 기억을 별도 후속 회상으로 기록한다.
- v47 기록은 parent를 통해 v46 선택과 연결되며, 연대기는 선행 선택과 다중 후속 분기를 추적한다.
