# v108 아셀 7일 연회 / 메인 스토리 구조

- INTRO: 마지막 날 대무도회 입장·입맞춤을 미래 장면으로 먼저 보여 줌. 이성/본능/경계 침범 첫 선택.
- 타이틀 카드 뒤 PROLOGUE: 초대장과 DAY 1~7. DAY 2~4는 3년간 사랑하게 된 과정의 회상. 정확한 원작 결정적 사건은 아직 제공되지 않아 새 사건을 정전으로 확정하지 않음.
- DAY 5: 알렉스가 영지 문제로 떠남. DAY 7: 귀환.
- DAY 7: 대무도회와 세 개의 달 아래 불꽃놀이로 프롤로그 폐막.
- ACT 01: 알렉스의 대리 요청으로 코트리먼 영지 방문, 수로 복구 사건. 기존 보존된 노란 장미의 주인 노드를 메인 스토리로 로드.
- 기존 저장 키 유지. 기존 노드 ID 삭제 없음. 구 저장 파일은 이전 노드에서 이어질 수 있음.
- 한계: 전체 3년 게임 흐름/모든 황궁 텍스트를 일괄 교정하지 않았고, 타이틀은 게임 내 스토리 카드이며 실제 홈 화면 전환은 아님.
