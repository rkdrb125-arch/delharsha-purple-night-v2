# v58 탐색 우선순위 및 동선 (게임용 각색)

- 기존 황궁 다섯 장소와 날짜별 NIGHT_SCHEDULES, 시간대별 NPC·인물 조우 로직을 유지한다. 신규 NPC의 출현을 확정 설정으로 추가하지 않는다.
- 방문하지 않은 장소를 먼저 제시하며, 단서 수집·약속·소문 등 진행 가능한 행동을 우선 표시한다.
- 30분이 필요한 행동은 해당 일자 이동 횟수가 모두 소진되면 특별 행동 목록에서 숨긴다.
- 오늘의 마음 선택은 한 번 실행한 뒤 그날의 메뉴에서 숨긴다. v58.actions는 저장 객체의 독립 필드이며 과거 저장에 없어도 자동 보완한다.
- 이미 완료된 연속 사건은 기존 퀘스트 완료 검사와 각 버전의 seen/stage 로직을 존중한다. 이전 기록 및 진단은 개발자 보관함에 남긴다.
- 메뉴는 3개 항목씩 페이지를 나누고 이전·다음·돌아가기 버튼을 유지한다.
- 장남의 정체는 미정이며 알렉스는 차남, 다니엘은 막내 셋째다. 미겔과 알렉스의 약혼은 유지한다.
- 본 문서는 게임 UI 구현 설명이며 공식 세계관 설정을 변경하지 않는다.
