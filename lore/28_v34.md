# v34 · 장기 재회와 선택 경로 연대기

## 공식 설정 (변경 없음)
- 다니엘 레온하르트는 레온하르트 가문의 동생이며, 알렉스 레온하르트는 형입니다.
- 미겔 코트리먼과 알렉스 레온하르트의 약혼은 **현재 유지 중**입니다. 미겔은 알렉스를 친근하게 **“알렉”**이라고 부릅니다.
- 미겔은 신중하고 실용적인 태도를 지닌 인물입니다. 다니엘은 정중하고 서툰 태도를 유지합니다.
- 황궁의 보라색 밤과 세 개의 달은 기존 세계관 설정을 따릅니다.

## v34 게임 전용 각색 (공식 원작 설정이 아님)
1. **미겔 장기 감정**: 솔직함·예의·거리 두기 선택을 감정과 절제 수치로 기록합니다. 충분히 만난 뒤 관계 분위기가 달라지고, 선택 후 이틀 이상 지난 재회에서 앞선 대화를 기억합니다. 약혼 해소나 관계 확정은 발생하지 않습니다.
2. **알렉 형제 갈등**: 대화 시도·회피 선택을 신뢰와 의심으로 기록합니다. 기존 v32 신뢰·의심 기록과 함께 후속 대화 분위기에 반영합니다.
3. **황궁 NPC 평판**: 친밀도가 높은 NPC의 부탁을 수락·거절하면 이틀 뒤 평판과 친밀도에 반영되고, 다시 이틀 뒤 추가 후일담이 등장합니다. NPC는 익명 역할 인물로, 제3자 소유 자캐를 새로 편입하지 않습니다.
4. **날짜별 서사**: 하루가 시작되는 첫 탐색에 전날 기록 또는 아직 해결되지 않은 후속 사건을 돌아보는 독백을 남깁니다.
5. **선택 경로 연대기**: v34 사건에 부모 사건 ID를 기록해 선택 → 결과 → 후일담을 열람합니다. 검색·인물 필터·정렬을 제공합니다. 이전 버전 회상 기록은 기존 메뉴에서 그대로 확인합니다.

## 저장 호환성
- 기존 `localStorage` 키 `delharsha_purple_night_v1`을 그대로 사용합니다.
- 새 데이터는 필요할 때 `state.v34`에 생성하며 이전 `v16`~`v33` 상태를 덮어쓰지 않습니다.
- 신규 이벤트는 기존 조우/이벤트보다 우선 표시될 수 있으나 기존 함수와 메뉴는 삭제하지 않습니다.
- 본 업데이트는 텍스트·대화·독백으로만 연출하며 전신 일러스트를 포함하지 않습니다.
