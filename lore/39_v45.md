# v45 — 관계의 여운, 형제 대화, 소문 관계망, 저장 검증

## 공식 설정과 게임 각색의 구분
- 공식 설정: 다니엘 레온하르트는 25세 남성, 미겔 코트리먼은 32세 여성이다. 미겔은 알렉스 레온하르트와 약혼 중이다. 다니엘은 알렉스의 동생이다.
- 게임 각색: v45의 선택지, 재회 대화, 형제 갈등·화해 단계, 궁인 소문망, 후일담과 수치는 플레이를 위해 추가한 비공식 사건이다. 약혼 파기나 연애 관계 확정은 발생하지 않는다.

## 사건 설계
- v44 완료 사건을 계기로 인물별 v45 재회 또는 NPC 소문 후속이 열림.
- 첫 선택 이후 2일 이상 간격으로 해당 인물/장소를 재방문할 때 최대 네 단계 진행.
- 미겔: 거리 유지 / 답을 강요하지 않는 솔직함.
- 알렉: 오해를 풀기 위한 대화 / 남은 의심을 직접 확인.
- NPC: 확인된 사실만 전달 / 확인되지 않은 말의 전파 중단. 장소별 누적 관계망 반응은 게임 각색.
- 사건마다 부모 사건 ID를 보관해 연대기에서 선행 선택 및 직접 후속 분기를 조회.

## 저장·검증
- 기존 `delharsha_purple_night_v1` 저장 키와 기존 백업 키 유지.
- v45 신규 상태는 `state.v45`에 지연 초기화하고 사건·선택 기록을 중복 저장하지 않음.
- 저장·백업 진단은 읽기 전용으로 JSON 파싱, 기본 저장 구조, v40~v45 사건 배열과 진행 단계의 기본 형태를 점검. 이 검사는 모든 브라우저 환경에서의 완전한 복구를 보장하지 않음.
- 전신 일러스트 없이 서술 중심 구성.
