# v56 — 플레이어용 메뉴 재구성

- v55까지 누적된 모든 탐색 버튼과 기존 콜백은 `v56CollectExplore`에서 등록하되, 메인 화면에 직접 출력하지 않는다.
- 메인 메뉴는 장소 이동 / 인물과 사건 / 회상과 이야기 기록 / 하루를 정리하기 네 항목으로 구성한다.
- 장소, 이벤트, 관계 기록, 연대기, 엔딩, 개발자 진단을 계층적으로 분류한다.
- 각 하위 목록은 한 페이지 3개 항목, 이전/다음 및 돌아가기 버튼으로 최대 5개 버튼을 유지한다.
- 기존 vXX 표기는 플레이어 메뉴에서 숨기되 기능과 콜백을 보존한다.
- 개발용 저장·백업·진단 버튼은 회상과 이야기 기록 > 개발자 도구에서만 접근 가능하다.
- 날짜에 맞지 않는 일부 사건 동작은 목록에서 감추고, 장소 방문의 기존 조건과 사건 진행 로직은 변경하지 않는다.
- 기존 엔딩 8종의 조건, 회상 기록 및 localStorage 저장 키를 변경하지 않는다.
- 이 파일은 UI 변경 기록이며 공식 세계관 설정을 변경하지 않는다.
