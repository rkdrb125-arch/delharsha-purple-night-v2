# v104 스크립트 검수 및 1차 교정 기록

## 실제 수정
- game.js의 오프닝/연회/온실/와인 사건에서 25개 정확한 문자열을 교체.
- 다니엘은 연회 이전부터 미겔을 사랑하며 억제해 온 상태로 묘사.
- 다니엘의 대외 호칭은 '코트리먼', 형에게는 '형님'을 우선 적용.
- 미겔의 사적 말투는 귀족 영애식 반존대(~니, ~렴, ~구나, ~단다 등)로 교정.
- CH01 세 번째 선택지 표시명을 '경계 침범'으로 수정. 기존 선택 분기 및 도덕 효과 유지.
- 기존 SAVE_KEY, 노드 ID, 분기 이동, 자산, 보류된 노란 장미 코드는 보존.

## 남은 검수 및 미확정 사항
1. 아셀 왕국 연회와 기존 델하르사 제국 황궁 무도회의 관계: 세계관 확정 필요. 현재 장소를 임의 변경하지 않음.
2. game.js 전체(약 47만 자)와 별도 lore 문서의 대사·서술 문장별 전수 교정은 아직 미완료.
3. 기존 36개월 게임 달력 및 조기 탈락 엔딩 구조는 아직 구현되지 않음.
4. 본편 노란 장미 ACT01~04는 deferred-story에 보류 중이며 ACT05~06은 미구현.
5. 기존 '후작님' 등 호칭과 감정 미확정 서술은 다른 노드/엔딩에도 남아 있을 수 있음.
6. 플레이어의 선택·세이브 데이터에 따른 실제 UI 회귀 테스트는 아직 진행하지 않음.
