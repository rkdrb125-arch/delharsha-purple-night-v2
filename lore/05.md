# 게임 시스템과 연출 — v10 기준

## 게임 방향
- 제목: **DELHARSA : 보라색의 밤**.
- 다니엘 시점의 로맨스 판타지 비주얼 노벨 + 황궁 탐색.
- 핵심 감각은 **프린세스 메이커에서 왕자님을 찾아다니는 듯한 탐색**: 미겔의 위치가 직접 공개되지 않으며, 없을 때도 일상이 진행된다.

## v10에 구현된 것으로 기록된 기능
- 대연회장, 대리석 회랑, 달빛 테라스, 응접실, 장미 정원 등 **5개 장소** 탐색.
- 시간 흐름과 미겔의 이동 시간표, 단서 수집, 조우 이벤트.
- 미겔이 없는 장소에서는 평범한 묘사나 익명 NPC와의 대화·선택지가 나온다.
- 장소별 19종, 전체 **95종의 일상 이벤트**(v10 README 기준).
- 와인 사고 이벤트, 관계 상태(호감도·신뢰도·결심·가문 평판·발각 위험), 인물 도감, 회상, 기록, 저장/불러오기.
- 다니엘·미겔의 공식 참고 이미지 사용.

## 연출 원칙
- 탐색 실패를 '미겔 없음'이라는 시스템 문구로만 처리하지 않는다.
- 같은 장소에서도 시종·경비병·귀족·정원사와 자연스럽게 마주치도록 한다.
- 미겔과의 만남은 평범한 일상과 대비되는 특별 이벤트로 연출한다.
- 다니엘의 예의, 머뭇거림, 책임감과 미겔의 절제된 말투를 유지한다.
- 알렉스와 미겔의 약혼 관계는 유지하며 금지된 감정의 긴장을 표현한다.
